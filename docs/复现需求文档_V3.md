# 几何拼接片 · 需求规格说明书（从零开发版）

> **本项目的唯一输入**：`卡扣元件.step`——一个卡扣的 3D 实体模型（含平整安装面与向外凸起的咬合结构，厚度 3mm，总宽约 10.4mm）。
> **除此之外的一切**（几何引擎、用户界面、服务器、下载功能）均由开发者（AI）依据本说明书从零实现。
> 技术栈不限（建议本地离线运行：Python 后端 + 浏览器前端，单文件 HTML，无需构建工具），但必须满足第 4 节硬性边界条件与第 7 节验收标准。

---

## 0. 交付物

一个本地运行的 Web 应用：
1. 启动后浏览器访问（如 http://127.0.0.1:8768），无需联网即可使用全部功能。
2. 用户选择/调整形状 → 实时 2D 与 3D 预览 → 下载 STL 文件，直接导入切片软件打印。
3. 形状由"拼片"组成：多片同规格的拼片可以通过卡扣互相拼接。

## 1. 产品概述

- **目标用户**：会 3D 打印的极客家长。懂切片、不排斥参数，但目的是几分钟内给孩子做出一片能用的拼片。
- **四步任务链**：①找到想要的形状（点一下就出来）→ ②调尺寸/镂空 → ③屏幕确认"长这样、能拼"（两片装配预览）→ ④下载 STL（文件名即规格）。

## 2. 核心产品规则（形状模型）

1. **标准单元 = 40mm 直边，每个单元边中点放 1 个卡扣。**
2. 形状 = 单元边的闭合排列；同一直线上相邻单元之间是 **180° 平滑顶点**（该顶点处 P1 圆角自动跳过、包边平滑通过、卡扣正常）。
3. **只有 40mm 单元体系的片才能互相拼合**；不同单元尺寸 = 不同比例体系，不互拼。
4. **40mm 整数倍边长自动放倍数个卡扣**：直线边 L ≈ 40k（k≥2，容差 ±0.5mm）拆成 k 条等长 40mm 单元边 + (k−1) 个 180° 平角顶点（拆分在提交给引擎前完成，2D/3D 与下载一致）；非整数倍边长（49、69.28、85）保持 1 卡扣；弧边不拆。
5. 形状支持：自由多边形（3–12 边）、正多边形、直线边、凸弧/凹弧；边长 12–160mm；弧半径 ≥ 弦长一半（上限 160mm）；可调内角 15°–300°。
6. 正多边形存在多个等价自由多边形解时提供"解"选择（正五边形/正六边形各有 2 解，解1 = 标准凸正多边形）。

## 3. 功能需求（引擎）

### 3.1 形状求解
- 自由多边形：给定边长数组（3–12 条）与 (n−3) 个可调内角，闭合求解全部解；默认解 0；解按 (最大内角, 面积) 排序。
- 无法闭合 / 自交 → 明确报错："无法构造满足边长与角度的简单多边形"。
- 弧边：凸弧（direction=out，向形状外部鼓出）与凹弧（direction=in，向内部凹进）。

### 3.2 参考线 P1 / P2（内缩）
- **P1 = 形状轮廓向内部严格等距偏移 3mm；P2 = 偏移 6mm。**
- 偏移语义：直线 → 平行线；圆弧 → **同心圆弧**（半径变化 ±偏移量，圆心不变）。偏移后曲线处处与原轮廓相距精确 3mm/6mm。
- 偏移失败（图形过薄/分裂）→ 明确报错并给出原因文案。

### 3.3 P1 顶点圆角
- P1 外轮廓顶点内角 [15°, 180°) 做切线圆角，半径 **0.05mm**（邻边过短时按 fit/tan(半角) 缩小）；≥180° 不圆角；<15° 或 >345° 跳过并红字提示"当前图形某内角小于15°/大于345°，暂不支持"。

### 3.4 卡扣安装（使用卡扣元件.step）
- 每边 1 个卡扣：平整安装面贴该边外侧、外伸方向 = 边外法线、长轴沿边方向、厚度方向与板一致（3mm）。
- 锚点：直线边 = 边中点在 P1 对应位置上的垂足；弧边 = 弦平面定位（锚点在中点附近、沿弧几何确定）。
- 卡扣与主体做最小 0.01mm 重叠的融合；融合失败（布尔退化）时需有备用策略保证卡扣最终连接。
- **边太短导致卡扣超出 P1 范围**：提示"边N太短，卡扣超出边框范围，无法生成几何片。"，此时前端跳过 3D 渲染。

### 3.5 包边
- 沿 P1 轮廓、每两个相邻卡扣之间分段，段内沿轮廓**外侧**铺一圈宽约 1mm、厚 3mm 的包边（与主体重叠 0.01mm），使拼片边缘圆润不割手。
- 分段规则（按顶点内角）：凸角 [15°,180°) 整段铺（含圆角弧连续）；180° 平滑过渡整段通过；**凹角 (180°,345°] 拆两段**——前段到顶点前 **0.05mm** 停、后段从顶点起（顶点处有 0.05mm 设计缝隙）；<15°/>345° 不铺。
- 包边两端与卡扣留空 **0.03mm**。
- 卡扣端面区间退化（放不下）→ 只跳过缺失段并记录。
- **硬性要求**：任何形状下，最终实体中每段包边都必须完整存在（不得整段缺失，见 4.2）。

### 3.6 主体 / 镂空 / 倒角圆角
- 主体 = P1 内部拉伸 3mm；弧边与安装弦平面之间的月牙补平（凹弧补、凸弧切）。
- 镂空：主体挖去 P2 内部（形成 3mm 厚夹层）；内孔上下棱做 0.75mm 倒角、倒角后新棱 R1.5 圆角（失败仅记录不阻断）。
- 板外竖直侧棱 0.03mm 圆角。

### 3.7 输出
- STL 下载（网格精度可容差 0.05mm）；文件名见 5.4。
- 3D 结果元数据：是否有效、卡扣连接数/总数、包边段数、跳过/失败清单、实际内角数组、体积、包围盒。
- 2D 结果：三条轮廓（P0/P1/P2）折线数据、卡扣位置、解数量、错误清单。

## 4. 硬性边界条件（必须满足，验收卡死项）

> 以下用例均为**用户真实输入**；实现必须让它们全部正常。若你的实现底层库存在缺陷，必须自行设计规避方案。

4.1 **崩溃规避**：下列"深凸弧"形状（四边 40×4，角 X°，边0 为凸弧 R20，X ∈ {50, 54.1, 60, 80, 85, 100, 120, 145.8, 90}；以及角 54.1° 时 R ∈ {20, 20.5, 21, 22}）必须能正常生成 2D 与 3D（valid、卡扣全连、包边完整），**不得崩溃、不得假死**。已知部分几何库对这些"弧端切线与邻边近共线"的形状在偏移操作时会崩溃——请自行检测并绕开。

4.2 **包边完整性**：下列六边形（边 40×6、角 120×3、解2）变体的**每段包边在最终实体中都必须完整存在**（逐段检查保留体积占比 = 100%）：
- A 无弧；B 边5 凹弧 R160；C 边4 凹弧 R40；D 边4 凹 R26.5 + 边5 凹 R40；E 边4 凹 R64 + 边5 凹 R64；F 边5 凹弧 R40。
- 已知风险：凹角两侧包边在顶点外侧必然空间交叉；逐段融合时后融合段可能被静默丢弃——请设计保证不缺失的融合策略。

4.3 **缝隙规格**：包边与卡扣之间缝隙必须为 0.03mm（**0.02mm 会在部分形状下导致包边被吞**）；凹角顶点处缝隙 0.05mm。

4.4 **偶发慢构建**：同一形状重复构建耗时可能大幅波动（底层布尔退化）；必须保证：单次构建超时 **60 秒自动中止并恢复服务**（返回"构建超时，请重试"类错误），期间页面其他功能不受影响；排队中的旧请求应被丢弃、只处理最新请求。

## 5. 前端 UI 需求

### 5.1 信息架构（三段式）

中栏（自适应，sticky 固定视口）：2D 小图（上）+ 3D 大图（下，整模入镜留边距）
右栏（320px）：①生成与下载（按钮+文件名+物料估算） ②高级（开发者）折叠区

- 品牌 header：「几何拼接片」/「给 3D 打印机的几何拼片工坊 · 每 40mm 边 1 个卡扣」。
- 一级卡片（带真实轮廓缩略图）：**三角形 / 四边形 / 五边形 / 六边形 / 其他多边形 / 曲边多边形**；点击展开变体（每变体带缩略图+名称）。"其他多边形"缩略图用通用虚线多边形图标（实线描边、与其他卡片同色）。
- 无"自定义"卡片：自由多边形编辑经"任意预设微调任一边/角/弧"自动转入。
- 细节面板：镂空开关（开关在文字**前面**）置顶 → 自动展开该形状**每条边、每个可调角**的滑轨（微调即转自由多边形）；不显示单元尺寸滑轨与冗长提示；自由多边形模式显示边数滑轨（3–12）；角区提示"共 N 个角，这里可调 N−3 个，其余由闭合求解自动计算。"。
- 2D 图例：轮廓（黑实线）、卡扣外沿（蓝虚线）、镂空内沿（绿虚线）、卡扣位置（红短直线：沿边切线、8mm 数据坐标随视图同比缩放；弧边取折线最近段切线方向）。
- 滑轨：行高 44px、轨道加粗、拇指 24px、CSS 刻度（边长 20mm/格、40 高亮"标准"；角度 15°/格）、不吸附、−/+ 微调与数字框并存。
- 3D：单色材质；两片装配预览默认开（第二片半透明天蓝，沿第 1 条边镜像+平移，纯前端）；相机拉远整模入镜。

- 状态栏仅异常/警告提示（成功态与生成中不显示；信息由按钮四态表达）。
- 高级（开发者）折叠区（右栏默认折叠）：快速参数粘贴框（支持 `58（凹弧，R40），40，40，40；角107.4°；解2` 与 JSON 两种格式）+ 复制当前用例 + 当前用例文本。
- 40 倍数拆边（第 2 节第 4 条）在提交前完成，2D/3D/下载一致；文件名用拆分前数据。

### 5.2 物料估算（3D 生成后显示于按钮旁）
- 显示格式：`打印约 X g · 物料成本约 X 元`（生成期间遮蔽为 `打印约 ** g · 物料成本约 ** 元`）。
- 实心件估算模型：2 层壁 0.8mm + 顶底 5 层共 1mm + 内部 15% 填充，由 2D 轮廓净面积 A（外轮廓−内孔）与总周长 P（外+内孔）计算：`V_print ≈ A×1.0 + A×0.15×2.0 + P×0.8×3 (mm³)`；重量 = V_print × 1.27 g/cm³ × **0.9**。
- 镂空件回退按实心体积 × 密度 × 0.9。
- 材质假设（hover 提示）：PETG 1.27 g/cm³、¥25/kg。

### 5.4 文件名（规格）
- 预设：`{名称}_{最大边长mm}_{镂空|实心}.stl`（例：`大正方形_80_镂空.stl`）。
- 正多边形：`正{n}边形_边长{mm}_镂空.stl`。

- HTTP 下载用 RFC5987 `filename*=UTF-8''…` 编码中文名；前端展示做中间缩略（超 46 字符截中加"…"）。

## 6. 服务与健壮性

- 3D 构建为耗时操作：构建期间页面 2D/其他功能不得阻塞；构建超时 60s 自动中止并恢复（返回"构建超时（>60s），已重启生成进程，请重试"）。
- 修改参数频繁触发 3D 构建时：只保留最新请求（旧请求排队中应丢弃；正在执行的允许按超时规则中止）。
- 2D 预览轻量（不含 3D 布尔），30ms 级防抖；3D 预览 1 秒防抖。
